### 게임 개요
게임 장르 : 턴제 로그라이크 / 미로 탐험

본 프로젝트는 C++과 WinAPI를 활용하여 개발한 턴제 로그라이크 미로 탐험 게임이다.

플레이어는 무작위로 생성되는 미로를 탐험하며, 맵 곳곳에 배치된 아이템을 획득하고 몬스터를 피해 출구를 찾아야 한다. 출구에 도달하면 다음 층으로 이동하며, 새로운 미로가 생성되는 방식으로 진행된다.

주요 게임 시스템

1. 랜덤 미로 생성
- 플레이할 때마다 새로운 미로 생성
- 벽과 통로를 구분하여 이동 가능 여부 판정
- 출구 및 오브젝트 배치
2. 턴제 이동 시스템
- 플레이어가 한 번 이동하면 몬스터도 한 번 행동
- 플레이어의 입력을 기준으로 게임 턴 진행
- 이동, 아이템 획득, 피격 등의 이벤트 처리
3. 몬스터 AI
- 몬스터가 플레이어를 추적
- BFS 알고리즘을 활용한 최단 경로 탐색
- 플레이어와의 거리 및 맵 구조에 따른 이동
4. 아이템 시스템
- 점수 획득 아이템
- 체력 회복 아이템
- 아이템 획득 시 플레이어 능력치 변경
5. 층 이동 시스템
- 출구 도달 시 다음 층으로 이동
- 새로운 미로 생성 및 게임 진행
개발 목적

WinAPI와 C++을 활용하여 객체 지향 프로그래밍의 기본 개념을 실제 게임에 적용하는 것을 목표로 한다.

상속과 다형성을 활용한 게임 오브젝트 관리, 클래스별 역할 분리, BFS 알고리즘을 이용한 몬스터 경로 탐색, GameManager를 통한 게임 진행 제어 등을 구현하며 게임 프로그래밍의 기초 구조와 작동 원리를 이해하고자 하였다.
